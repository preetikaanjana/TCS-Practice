# 🚀 TCS NQT - 10-Day Advanced Coding Sprint

Welcome to the **TCS NQT 10-Day Advanced Coding Sprint**! This plan contains **72 high-yield problems** meticulously selected from the original 100-problem blueprint. Repetitive variants have been trimmed so you can focus maximum effort on high-impact patterns (Two-Pointer, Sliding Window, DP, Matrix, and actual TCS PYQs).

---

## 📌 Strategy & Schedule Overview

| Day | Focus Area | Problem Count | Why it Matters |
| :---: | :--- | :---: | :--- |
| **Day 1** | Number Theory | 8 | Fast warm-up, pure logic, prime for Q1 |
| **Day 2** | Arrays - Level 1 | 14 | Core Q1 material & fundamental array manipulations |
| **Day 3** | Strings - Level 1 | 10 | Core Q1 material & string manipulations |
| **Days 4–5** | Two-Pointer & Sliding Window | 14 | **Highest yield for Q2** — Converts $O(N^2) \rightarrow O(N)$ |
| **Day 6** | Matrix Patterns | 8 | Common Q2 grid & spatial logic |
| **Days 7–8** | DP & Greedy | 10 | **Highest yield for Q2** — Most feared, most rewarding |
| **Day 9** | Actual TCS PYQs | 15 | Exact story-based problem style TCS reuses |
| **Day 10** | Timed Mock Test + Revision | — | Simulate real exam pressure |

> ⚠️ **Rule of Thumb:** Try solving every problem on your own without looking at the solution for at least **15–20 minutes**. That initial struggle is what builds test readiness.

### ✂️ Summary of Trimming (What was cut & why)
* **Removed:** Automorphic, Abundant, Octal-to-Decimal numbers, Array Average/Median, Remove non-alphabetic chars, Sum-of-digits in string, Capitalize-edges, Matrix Addition/Subtraction, and Boundary Traversal.
* **Reason:** These test skills already covered by kept problems. In a 10-day sprint, repetition has a lower return on investment than an extra pass through DP and Two-Pointer logic.
