# 🚀 TCS NQT 100 Coding Problems Blueprint

This repository contains **100 curated coding problems, patterns, and Previous Year Questions (PYQs)** meticulously categorized to help you clear the **Advanced Coding Ability** round of the TCS NQT (Ninja, Digital, and Prime profiles).

## 📌 Syllabus & Weightage Breakdown

| Section | Target Profile | Difficulty | Focus Areas | Recommended Time |
| :--- | :--- | :--- | :--- | :--- |
| **Question 1** | Ninja / Digital | Easy - Medium | Arrays, Strings, Number Theory, Basic Hashing | 25 - 30 Mins |
| **Question 2** | Digital / Prime | Medium - Hard | Matrix, Two-Pointer, Sliding Window, DP, Trees | 45 - 50 Mins |
